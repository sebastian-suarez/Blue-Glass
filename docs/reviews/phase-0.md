- **Mermaid's layout made parity captures flaky.** Mermaid lays its diagrams out asynchronously, so captures now wait for a stable layout.
- **A MenuList typeahead test was timing-dependent.** It failed once under a full parallel run. Typeahead now takes its timing from key events' timestamps, and the test has no sleeps. Five full runs passed.

### Rejected

- **#11, the server render's clock.** A component that renders the current time can't hydrate cleanly in production either, because the server and the browser read different clocks. The harness's mismatch exposes that hazard, so it stays. No preview renders a date or time today.
