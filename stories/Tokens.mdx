# Tokens

Every value in Blue Glass comes from `design-system/tokens/tokens.json`, and this page is generated from it. The stylesheet declares each token as a custom property on `:root` and each type style as a `.text-*` class, so `var(--color-ink)` and `class="text-heading"` work anywhere it loads.

## Colour

One light theme. Each note gives the colour's role and the contrast it reaches on the canvas and on glass.
