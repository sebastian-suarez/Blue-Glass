# Blue Glass design system

The look of sebastiansuarez.dev as data: brand book, tokens, styles and every component's spec, preview, API and current implementation. Read from it; nothing here is meant to be imported or built as is.

Exported on 2026-10-21 from the Blue Glass artifact (latest change: "Mermaid polish", `MermaidDiagram` now draws with `Diagram`'s marks), originally synced from `sebastian-suarez/portfolio@2fc0fe9`.

66 components and 5 sections. Only `Diagram`, `TimingChart`, `PaneAccordion`, `LightField`, `MermaidDiagram` and the glyph set in `Icon` are specific to Blue Glass; the rest follow MUI's catalogue.

## Reading one component

1. `components/<Name>/README.md`, for what it must do.
2. `components/<Name>/styles.css` and the files its header points to, for how it looks.
3. `components/<Name>/api.d.ts`, for its public props.
4. `components/<Name>/preview.html`, for its states and copy.
5. `components/<Name>/reference.tsx`, for markup and details.
6. `brand-book.md`, for any rule the above don't cover.

## Known facts about the source

Checked while packaging it earlier today, on React 18.3 and 19.3:

- **Every component renders on the server**: no `window` or `document` during render; popups render nothing until open.
- **React 19 types:** the sources typecheck clean on React 18 types but not on React 19's. The fixes: ref parameters typed `RefObject<T | null>`, `cloneElement` calls widening the element's props, type-only imports under `verbatimModuleSyntax`, and a `CSSProperties` augmentation for `--*` keys in `style`.
- **Runtime:** `Tooltip` and the transitions read a child's ref from `props.ref`, which React 18 drops in development; `Select` spreads a `key` into `Option`.
- **`MermaidDiagram`** loads `mermaid@11.16.1` from jsDelivr at runtime (its `src` prop); a package would import it instead.
- **`tokens.css`** isn't published by the artifact (its page generates it); `tokens/tokens.css` here is generated by `tools/build-tokens.mjs` with the same rules.
- **Fluid display type:** the tokens hold desktop sizes; `Typography`'s `fluid` prop applies the site's `clamp()` values.

## Regenerating after a design-system update

Download the artifact's `project/` folder (a Claude session with the Artifact tool can), then from this folder:

```sh
python3 -I tools/build_reference.py <download>/project .
node tools/build-tokens.mjs --strict
```

The first rewrites everything except this README, `tools/` and `tokens/tokens.css`; the second regenerates `tokens/tokens.css`.
